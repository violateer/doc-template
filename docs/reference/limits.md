# 边界与取舍

## 已实现

- 模板元数据 CRUD、文件上传 / 版本 / 下载 / 预览、删除时同步清理存储对象；
- 数据块 CRUD（表单化配置）与执行器（Java Provider / SQL / API 三种数据源）；
- DOCX / XLSX 占位符渲染（含明细行循环、递归嵌套与图片字段）；
- 模拟生成、内置 PDF 导出、生成记录与结果文件；
- Provider 列表；
- 可插拔认证（`none` / `custom`）；
- 嵌入式管理页面（模板信息与数据块合并为双 Tab 弹窗）；
- 结构化标注：文档结构快照、按计划落笔、模拟数据自检、一键生成数据块（值 / 行循环 / 区域循环三类标记；动态列与嵌套循环不支持，计划里出现即跳过，可在模板里手写）；
- 可选的模型出计划（OpenAI Chat Completions 兼容，默认关闭，失败回灌重试）；
- AI 导入任务：上传建任务、后台执行并显示阶段、可取消 / 重试 / 删除，成功后在 APPLY 阶段一次建好模板与数据块；
- 示例 iframe / 代理 / 认证配置。

## 尚未实现

| 未实现 | 替代方案 |
| --- | --- |
| 复杂模板语法（条件判断、图表） | 数据块返回不同数据，或拆成两份模板 |
| 异步生成任务队列 | 当前同步生成，大文档注意超时设置 |
| 细粒度业务数据权限适配器 | 用 `DocumentDataProvider` 在业务层控制 |
| 公式重算 / 目录域更新 | 由 Office 打开后手动更新 |
| 循环区里的跨行合并格 | 竖向合并用 `{{#each ... merge=列 by=字段}}` 声明（见[模板标记](/guide/template-syntax)）；模板里自带的跨行合并区在循环块内会被移除 |
| 标注嵌套表格里的内容 | 快照只列正文顶层表格；先把嵌套表拆成顶层表格，或在管理页手工补标记 |
| 标注段落区域循环（多段整体重复） | 表格行区域循环已支持；段落层面目前只能逐个值标注 |

## 明确不做

| 不做 | 原因 |
| --- | --- |
| 权限码 / 菜单 / 角色 | 只认证不授权，宿主自己的权限体系管 |
| 内置认证框架适配器 | 宿主桥接 3~5 行，内置换来 optional 依赖与 `NoClassDefFoundError` 风险 |
| 自带 `application.yml` / 连接池 | 保证 jar 零外部依赖配置，宿主配什么用什么 |
| 复用宿主 OSS/MinIO 客户端 | 存储配置独立，避免隐式耦合 |
| 内置登录页（发布物内） | 示例工程里的登录仅用于演示 |

## 安全取舍

### SQL 数据块

模块做了三层防护（语句白名单、关键字黑名单、只读连接）和错误脱敏，但**这三层不是安全边界**：

- 解析器不认识的方言写法会直接报错（宁可拒也不放过）；
- 也有驱动只把 `setReadOnly` 当提示、并不真的生效；
- 配置写权限本身就是风险：能打开数据块编辑页的人就能配一条查询。

真正可靠的措施是**宿主给模块配只读数据库账号**，以及对外系统直接关掉 SQL 数据源。

### API 数据块

- 只允许 `http` / `https`；
- 可用 `allowed-hosts` 限制主机（默认不限制，等于放开 SSRF 面）；
- 超时上限 `max-timeout-ms`（默认 15s）避免线程被长时间占用。

### 认证

- `none` 模式对能访问到端口的调用方完全开放，生产禁用；
- `custom` 模式只保证「知道是谁」，不保证「能做什么」；
- 401 与 500 的区分依赖 `DocTemplateAuthorizer` 返回 `null` 而不是抛异常。

## 工程约定

| 约定 | 说明 |
| --- | --- |
| JSON 只用 Jackson | 不引入 Fastjson，实体转 Map 走 `DocTemplateJson` |
| 工具方法用 Hutool | 判空、文件名、摘要、类型转换不手写 |
| SQL 参数走占位符 | 一律 `NamedParameterUtils` 绑定，绝不拼进 SQL 文本 |
| 异常对外脱敏 | 数据库原文只进日志，兜底 500 不回传内部信息 |
| 研发阶段不保兼容 | 旧配置项该删就删，不留废弃别名 |
